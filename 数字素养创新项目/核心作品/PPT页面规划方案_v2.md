# PPT 页面规划方案（第二版）

> 上一版被否掉的原因：① 没先给规划就做了成品；② 整页纯文字色块，一张真实画面都没有，所以丑。
> 这一版先只给方案，你认可哪一版再动手。

---

## 〇、这一版的核心改变

**上一版是"讲道理"的 PPT，这一版是"看见"的 PPT。**

差别在于：每个技术点都配一张视频里的真实画面，而且统一用同一个句式讲清楚——

> **这项技术，在什么环节、什么过程中、怎么用、达成了什么目的。**

这句话就是评委要的答案。下面把它做成标准格式：

```
【技术】  用了什么
【环节】  在课堂的哪一步用（课前 / 课中讲 / 课中练 / 课后复盘）
【过程】  学生具体做了什么动作（一句大白话，不带术语）
【目的】  解决了什么问题（一句话，别人能立刻点头）
```

## 一、六项技术落点（这是全案的骨架）

这六条我认为是这个作品真正的技术含量所在。每一条都经得起评委追问"这里面到底用了什么"。

### 落点 1 · 一间真驿站，2 秒进机房

| | |
|---|---|
| **技术** | 一张 4096×2048 的实景照片 + 球面包裹 |
| **环节** | 课前情景导入 |
| **过程** | 学生双击打开一个网页 → 那张驿站实拍照片被贴在一个大球的内壁上 → 拖动鼠标，就像站在驿站中间转头看，前后左右都是真的 |
| **目的** | 不用 3D 建模、不用买头盔、不用装软件。**一间真驿站，2 秒进机房** |

> 大白话一句：**就是把一张照片，变成一间可以走进去的屋子。**

### 落点 2 · 在照片上给五样东西标了位置

| | |
|---|---|
| **技术** | 全景图上的位置标记 + 镜头自动推近 |
| **环节** | 课中任务触发 |
| **过程** | 在照片上给信封、扫码枪、账本、笔记本、宝箱这五样东西各标了一个位置 → 学生点信封，镜头自动推近到信封上，同时弹出店长留下的信 |
| **目的** | 任务顺序由"东西在哪儿"决定，不是一张从上到下的菜单。**学生是在场景里找东西，不是在页面上点按钮** |

> 大白话一句：**照片里那张桌子上的东西，都能点。**

### 落点 3 · 把"顺序·条件·循环"变成看得见的运动

| | |
|---|---|
| **技术** | 实时 3D 动画 |
| **环节** | 课中讲抽象概念 |
| **过程** | 讲"知识大厦"时，一页页课件变成纸片飞起来，一层层摞成一座楼；讲"机器人车间"时，机械臂真的伸过去把包裹抓起来放进格口，屏幕上跳出"任务完成" |
| **目的** | "顺序、条件、循环"是看不见的程序逻辑。**变成纸片怎么摞、机械臂怎么动，学生一眼就懂** |

> 大白话一句：**抽象的东西，给它做成能动的实体。**

### 落点 4 · 摄像头看着你的手，但视频不出这台机器

| | |
|---|---|
| **技术** | 摄像头 + 手部 21 个关节点识别 |
| **环节** | 课中答题互动 |
| **过程** | 摄像头拍到学生的手 → 屏幕上实时画出 21 个点和连线（像手部骨架）→ 学生比"1"或"2"、"对"或"不对" → 对应的选项被选中，得分 20 |
| **目的** | 不用键盘鼠标，全班都能同时答。**关键：所有计算在学生自己这台电脑上完成，视频不出机器、不上传、不保存** |

> 大白话一句：**它看得见你的手，但它看不见你——画面根本没离开这台电脑。**

### 落点 5 · 断网也能用，因为整个作品就一个文件

| | |
|---|---|
| **技术** | 所有图片、音频、模型全部打包进一个 HTML 文件 |
| **环节** | 全流程部署 |
| **过程** | 一个 13 MB 的文件，双击就开。图片、语音、3D 场景都在里面，不需要联网、不需要装插件、不需要服务器 |
| **目的** | **机房 41 台老机器同时开也不卡；拔掉网线照样上课；U 盘拷走就能带走** |

> 大白话一句：**它不是一套系统，它是一个文件。**
> 这一条是全场最硬的技术底气，也是最容易被评委记住的点——因为绝大多数作品现场演示都要先连网。

### 落点 6 · 每一分都查得到出处

| | |
|---|---|
| **技术** | 原始台账（Excel）→ 汇总看板 |
| **环节** | 课后复盘 |
| **过程** | 学生手写的加分记录 → 录入 Excel 原始表（41 行 × 三次课）→ 看板自动算出参与率、平均分、最高分 180 |
| **目的** | 看板上的每个数字，都能点回去看是哪一次课、哪一个人加的。**不是 PPT 上画的图** |

> 大白话一句：**看板上的数，翻得到底账。**

## 二、把六项落点装进"一堂课的四个环节"

这是这一版 PPT 的叙事主线。为什么用这个做主线：

- 评委都是教育口的人，**最懂"一堂课"**，不需要任何解释就能跟上
- 技术点自然落进环节里，不会变成功能罗列
- 天然体现"真课堂"——因为讲的就是那节课本身

```
课前 30 秒  →  课中讲  →  课中练  →  课后复盘
  落点1        落点3      落点2+4      落点6
  进驿站      听抽象课    做五步任务    看数据
      └──────── 全过程靠落点5：一个文件 ────────┘
```

## 四、视觉设计怎么改（针对"太丑"）

### 上一版为什么丑（自查）

| 问题 | 具体表现 |
|---|---|
| **没有一张真实画面** | 全是文字块和圆角矩形，像 Word 文档 |
| **配色没有主次** | 米白底 + 橙 + 绿平均用力，没有"深色压场" |
| **信息密度太高** | 每页塞 20 多个元素，眼睛不知道看哪儿 |
| **版式太规整** | 三卡片、四宫格、均匀间距，像模板套出来的 |
| **字号对比不够** | 标题 34pt、正文 14pt，差距太小，没有视觉冲击 |
| **没有节奏** | 8 页全是同一个亮度，看到第 3 页就疲劳了 |

### 这一版的设计规则

**① 每页必须有一张真实画面，且占页面 40% 以上**

这是最大的改变。真实课堂的画面本身就有说服力，比任何设计都强。

**② 建立"深—浅—深"的节奏**

```
P1 满图（亮）  P2 分屏（亮暗对比）  P3 浅底  P4 浅底
P5 浅底  P6 深底满图  P7 浅底  P8 深底
```

P6 和 P8 用深墨绿底，让全场有两次"变暗"，评委的注意力会被重新抓住。

**③ 配色收窄到三个色**

| 色 | 值 | 用途 |
|---|---|---|
| 深墨绿 | `#0E3B33` | 深色页底、标题强调 |
| 米白 | `#F6F3ED` | 浅色页底（比纯白柔和，投影不刺眼） |
| 暖橙 | `#E8722A` | **只用于**序号、箭头、关键数字。（和机器人同色，有呼应） |

其余全部用灰阶。**橙色一页最多出现 2 处**，才有力量。

**④ 字号拉到大对比**

- 主标题 54–72pt
- 一句话结论 32–40pt
- 正文 14–16pt
- 备注 11pt

**⑤ 每页元素不超过 3 组**

图 / 一段三段式文字 / 一句结论。就这三样。

**⑥ 全出血 + 压字**

图片不留白边，直接出血到画布边缘；文字压在图上，加一层渐变保证可读。这是纪录片海报的做法，教育类 PPT 里很少见。

## 六、需要你确认的三件事

**① 投影比例是 16:9 还是 4:3？**
如果是老投影仪 4:3，我要把关键信息收进中间安全区，左右可以出血给图。这个必须提前定，做完改不了。

**② 配色你倾向哪个？**

- **A 深墨绿 + 暖橙**（现在方案用的）— 沉稳、有教育感，和机器人橙色呼应
- **B 学院蓝 + 金**（`#0F2A4A` + `#C9A227`）— 更"学术汇报"，安全但普通
- **C 墨黑 + 朱红**（`#1A1A1A` + `#C62828`）— 更有力量，但偏"发布会"

**③ 要不要我先出 1 张样张？**
我可以先只做 P6（手势答题那一页，深底 + 满图），你看效果。认可再往下做完 8 页，不认可就只浪费一页的时间。
