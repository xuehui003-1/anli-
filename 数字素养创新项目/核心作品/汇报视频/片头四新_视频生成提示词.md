# 片头「四新」段 · 视频生成提示词

> 说明：这一段不用 AI 视频生成，**用字卡 + 配音 + 原片**拼最快、最稳、字最清。
> 下面第一节是「剪辑版提示词」（照这个做，10 分钟出片）；
> 第二节才是给 AI 生成器用的提示词（只在你想做动态背景时才用）。
> 两种都不要用 AI 生成「中文字卡」——AI 生成的中文十有八九是乱码。

## 一、剪辑版提示词（推荐，直接照做）

**【任务】** 在现有成片 `四真版_成片.mp4` 的第 5.8 秒「真课件 · 真任务 · 真数据 · 真课堂」这句之后，插入一段 26 秒的「四新」说明，之后接原片第一章「一 · 真课件」。不允许删除、改动原片任何内容。

**【素材】**
- 原片：`汇报视频/四真版_成片.mp4`（1:51，1920×1080，30fps）
- 字卡 3 张：`汇报视频/片头四新_字卡/`（1920×1080 PNG）
- 配音：`汇报视频/片头四新_配音与字幕.txt` 第一节（268 字）
- 字幕：同文件第二节（12 条）

**【时间线】**
| 位置 | 时长 | 画面 | 声音 |
|---|---|---|---|
| 原片 0:00–0:05.8 | 5.8s | 原片（小邮伴学 + 四真） | 原声不动 |
| 插入 1 | 2.8s | 卡1（四真之后还有四新） | 配音第 1–2 句 |
| 插入 2 | 20.2s | 卡2（四真对四新，四行停住） | 配音第 3–6 句 |
| 插入 3 | 3.0s | 卡3（四真没编 / 四新改过） | 配音第 7 句 |
| 原片 0:05.8 起 | 剩余 | 原片第一章接回 | 原声不动 |

**【视觉规范】**
- 底色 #F6F3ED 米白、主色 #0E3B33 深墨绿、强调色 #E8722A 暖橙、深橙 #C05514
- 字体：思源黑体 SC（Bold 用于标题，Regular 用于正文）
- 字号：一级标题 ≥ 88px，正文 ≥ 34px（1920 宽下投影仍可读）
- 字卡之间交叉溶解 0.4s；卡内文字不动、不做飞入、不加粒子特效
- 全片右下角不加任何角标、水印、进度条

**【音频规范】**
- 配音音量 -6 dB，原片原声压到 -20 dB（只在插入段压，接回原片后恢复）
- 插入段不要背景音乐；接回原片第一章时音乐淡入 0.5s
- 齿音、口水音剪掉，句间留 0.4s 气口

**【禁止】**
- 不许出现英文单词、不许出现技术黑话（锚定、SLAM、场景包、交互范式）
- 不许把「小邮」写成机器人、AI 助手
- 不许把四新写成四个并列的「功能」，必须每句都带「真 X → 新 Y」的对照

**【输出】**
`四真四新版_成片.mp4`，1920×1080，30fps，H.264，音频 AAC 192k，时长约 2:17。

## 二、AI 生成版提示词（只在需要动态背景时用）

以下三条各自独立生成 5–8 秒的**纯背景动效**，不带任何文字，事后把字卡叠在上面。
三个生成器都吃这一套写法：**画面 + 运镜 + 光线 + 时长 + 负面词**。

像四条正在被"点亮"的轨道；轨道尽头有极小的一点暖橙 #E8722A 光晕，光晕缓慢呼吸。
镜头固定不动，轻微颗粒感，无反光无高光溢出，无文字无图标无人物。
时长 6 秒，24fps，柔和渐入渐出。
```

### 提示词 B（对应卡2 · 四真对四新）

无文字无数字无图标无人物，扁平无阴影，克制留白。

### 提示词 C（对应卡3 · 收口）
```

### 生成后的处理
1. 三个片段按 2.8s / 20.2s / 3.0s 截断（B 段循环或放慢到 20s）
2. 把对应字卡 PNG 叠在最上层，不透明度 100%
3. 按第一节的音频规范配配音与音量
4. 严禁让生成器直接生成中文字——一定会乱码
